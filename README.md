# Mosshell Codex Pet

Mosshell is a tiny frog wearing the original leaf mask. The leaf stays visible as the identity, with eye-shaped cutouts for the real eyes.

## Install

Keep `pet.json` and `spritesheet.webp` together in a folder named `mosshell`.

Windows:

```text
%USERPROFILE%\.codex\pets\mosshell\
```

macOS/Linux:

```text
~/.codex/pets/mosshell/
```

Then restart Codex, or open Settings → Pets → Refresh, and select Mosshell.

If `CODEX_HOME` is configured, use `<CODEX_HOME>/pets/mosshell/` instead.

## Package

- `pet.json` — v2 pet manifest.
- `spritesheet.webp` — 8 × 11 transparent animation atlas, 1536 × 2288 pixels.

Preview images and QA notes are included for inspection only; Codex needs the two files above.

## Status

The atlas passed deterministic v2 validation, chroma cleanup checks, cardinal-anchor checks, blind direction review, 16-direction semantic review, and independent visual QA.
